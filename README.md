# Jenkins & GitHub Integration Practice

This repository is used for practicing Jenkins CI/CD pipeline integration, source code checkout, and basic workspace verification.

## Pipeline Stages
1. **Checkout**: Pulls code from the `main` branch.
2. **Verify Workspace**: Runs diagnostic commands (`pwd`, `ls -la`, `whoami`).
3. **Build**: Simulates the build process.
4. **Test**: Simulates the testing process.
